## 02 / THINGS I MADE

<br/>

**COSMOS** — *a universe, simulated*
N-body gravity. Stars pull on planets, planets pull back, black holes don't care either way.
`Canvas` · `Physics` · `JavaScript`
→ [github.com/Pragati7058/cosmos-simulator](https://github.com/Pragati7058/cosmos-simulator) · [try it](https://Pragati7058.github.io/cosmos)

<br/>

**STUDYMIND** — *an AI that actually tutors*
Six modes, three languages, one Claude API key doing a lot of work.
`Claude API` · `JavaScript` · `Marked.js`
→ [github.com/Pragati7058/studymind](https://github.com/Pragati7058/studymind) · [try it](https://Pragati7058.github.io/study-mind)

<br/>

**SPECTRA** — *sound, made visible*
Web Audio API pushed into four different visual moods. Retro sci-fi, on purpose.
`Web Audio` · `Canvas` · `JavaScript`
→ [github.com/Pragati7058/spectra-visualizer](https://github.com/Pragati7058/spectra-visualizer) · [try it](https://Pragati7058.github.io/spectra)

<br/>

**CINEVAULT** — *a movie search that feels like one*
TMDB-powered, with a watchlist and cast modals that don't feel bolted on.
`TMDB API` · `JavaScript` · `CSS`
→ [github.com/Pragati7058/cinevault](https://github.com/Pragati7058/cinevault) · [try it](https://Pragati7058.github.io/cine-vault)

<br/>

**AETHER WEATHER** — *weather that looks like the future*
Dark glassmorphism, live data, a UV gauge nobody asked for but everybody needed.
`Open-Meteo` · `JavaScript` · `CSS`
→ [github.com/Pragati7058/aether-weather](https://github.com/Pragati7058/aether-weather) · [try it](https://Pragati7058.github.io/aether-weather)
