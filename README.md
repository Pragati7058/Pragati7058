## ⚡ About Me

Hey there! I'm **Pragati**, a **Flutter Developer Trainee at Softgrid Info Pvt. Ltd.** and a fresh **B.Tech Computer Science & Engineering** graduate from **DBATU (2026)**, building apps from **Latur, Maharashtra, India** 🇮🇳.

* 🛠️ **How I work:** Turning product flows and Figma wireframes into responsive mobile interfaces backed by clean REST APIs and real-time data.
* 🌱 **Currently leveling up:** State management, clean architecture, and system design.
* ☕ **Off-screen fuel:** Good chai, neat UI details, and debugging tricky edge cases until they click.
